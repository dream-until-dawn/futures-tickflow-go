# 两道数据门槛 v2 与模拟手数

2026-11-17，用户明确取消“实际最低开仓手数”作为回测硬项。新版只调整数据条件，不修改真实交易所规则，不改写旧原件，不自动设置账户或策略参数。

## 当前规则

第一道回测仅含 `history_ohlc` 和 `current_margin`：2021年前后至近期的逐年有效OHLC日线观察，之后上市者需有上市日起点的直接证据；当前保证金需明确日期、具体合约、比例单位和发布者。当前参数回放历史属于情景，不是历史实际制度。公司公开标准与交易所比例分别显示，不保证等于账户实收。

第二道仍仅含 `settlement` 和 `daily_update`：目标已收盘日的有效结算和按交易日抓取、校验、更新能力。已有能力独立记录；逐品种推进时第一道受阻就记缺口转下一品种，不据第二道已通过冒称回测资料齐备。

实际最低开仓（包括专项）保留为补充项。真实未知仍为 `effective_min_open_lots=null`，不从普通最小报单或保证金推成1手。任务可显式设置较大的模拟手数；模拟值和实际规则分字段，不能声称某个较大值必然覆盖所有真实专项。数据侧不选定统一数值，不修改引擎任务、固定一手旧行为或真实账户限制。

## 机器字段与兼容

逐品种评估 `schema="user-data-gates-v2"`，`backtest.hard_items` 精确为 `history_ohlc/current_margin`；`daily_signal.hard_items` 精确为 `settlement/daily_update`。各项状态仍为pass/pending/not_met，证据、具体合约和阻塞原因保持原字段。两版本硬项集合不能混用。

`supplementary.effective_min_open` 保存已核实际最低开仓范围或待补证原因，不参与v2第一道状态。`simulation_assumptions.minimum_open_lots=null` 表示本数据评估未配置模拟值；`configured_by="consumer-task"`、`is_actual_rule=false`、`applied_to_engine=false`，明确模型假设由消费任务配置。

旧[机器接口v1](user-data-gates-format.md)和已封存的真实交付包保持原字节、三项硬条件与原SHA。两个旧包生产器已显式固定按v1计算，不能在升级数据表时无声改变它们。引擎若消费v2须显式按版本分发；数量相关的资金、费用、盈亏计算需由引擎独立验证，不只改一处资料检查。

## 本轮复算与边界

按既有冻结事实复算全部81个商品：42品种/460个当前合约范围满足第一道，52品种/527个范围满足第二道，两道都满足42品种。第一道分布为上期所20、能源中心5、郑商所17；大商所和广期所目前0。全项目另列中金所6个第一道品种/21个范围，不混入商品交付。

这些是**资料条件评估**，不是42品种已完成引擎回测，不是42个完整可执行交付包。历史逐年有效日期数不等于挂牌全集无缺日；版本、零成交语义和既有对账差异照旧待核。最新已收完整原件的行情日仍为2026-11-16，参数对应17日；不声称17日盘后或18日已更新。

复算账本见[81商品逐项报告](evidence/product-gates-v2-20261117.json)，每项列两道状态、具体范围、硬项缺口及下一阶段；其中39个第一道待补证，逐项原因可查。报告绑定输入路径、长度和SHA，只含资料评估，不含价格负载，不可直接当作引擎执行包。可点击详情见[数据情况表](data-status.html)。引擎独立验收和运行成熟度另列，未新增任务或部署。

本轮数量增加来自用户取消最低开仓硬条件，不是新下载了41品种历史行情；旧失败来源不重试，线上CI继续跳过，本地验证结果另记。不打tag。
