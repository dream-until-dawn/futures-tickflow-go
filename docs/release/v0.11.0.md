## 变更与迁移

- 内置日历支持通过 `embedded.NoNightAfter` 注入交易所公告中的停夜盘日期，derivedreport 可使用同一名单解释差异。名单对全部有夜盘品种生效，不能表达不同交易所同一天不同安排；不维护官方交易日表。
- `embedded.New` 现接收可变选项。普通直接调用保持可用，但将它赋给旧的单参数函数类型时须用包装函数；不能笼统声明所有源码兼容。
- Syncer、Feed、行情 Client 必须共享同一份注入日历。只修改其中一个组件不能消除停夜盘错误；日历覆盖不足仍须报错。
- `adapter/` 是单独 Go 模块，继续固定下游记账内核依赖；只做已支持的分钟数据衔接，不把历史回放解释为交易、下单或资金链路验收。根模块当前使用本地 replace，发布前须核查下游独立安装方式和版本引用。
- 增补多模块审计、采集进程生命周期与活性监护、证据封存迁移、具体合约末根录制及只读 NTP 区间采样。不修改系统时钟，不承诺行情总能在四秒内稳定。
