## 没做到的

```
一  实时主连不做（主连模式的 Feed 不收 Push）；日内主连仍不做（U5）；纯实盘不带历史不做（NewFeed 的 src 不许 nil）
二  实时落库不做（L11）：Live 交出的根不写 Store，库里的由之后的 Sync 拉
三  一个 Live 只推一个合约；Live 与 Feed 都不是并发安全的
四  实盘读数只有 rb 一个品种、三次取数；夜盘末根的 G 只有 6.36 一个样本（外推）
五  没见过：服务端主动断线 · 断线超出推送窗口（30 根）之后的重连补齐（只有离线测试）· 停夜盘日的实时 · 不活跃品种（「每分钟有根」的前提可能误报跳格，方向是停下来）
六  L9（trading_day_end_id 与日历的交叉校验）没做
七  Live 交出的根按本机时钟可以早于 TsEnd（6.39：中位早 502 ms）⇒ 别拿本机时刻对它跑 CheckBars（契约里写明）
八  沿用 v0.9.0「没做到的」各条（AggRule 默认没实测 · 时钟网格没有真实行情数值对照 · Feed 只收单段 coverage · 库扫两遍 · 更早版本沿用的各条）—— 本版没有动它们
```
