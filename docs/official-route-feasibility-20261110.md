# DCE/GFEX新公开路线有界核验

## 事前方案与预算

仅核查正常公开官方HTTPS路线，不修改公共接口或现有DCE/GFEX网络门禁。先读本机旧失败记录建立URL拒绝表；不重复其中失败URL，不绕过TLS、不指定替代IP、不使用凭据、不购买或部署。若需要验证码、登录或安装客户端即停在该边界。

预算冻结：浏览发现最多8次工具请求（已用2次搜索）；本机直接HTTP总计最多12次、每市场最多6次、每次15秒、累计正文最多24MiB、单件最多4MiB，总直接取证时间最多240秒；不跟随重定向，不自动重试。依页面实际链接选择新入口，脚本/数据请求也计入预算。响应失败保留状态与正文；HTTP200但非行情不算取得历史数据。取证目录单独冻结plan、逐请求UTC、SHA256及字节，不改写旧证据。

输出区分：发现入口、连接成功、结构可解析、实际业务日支持、连续年份覆盖；不能从一个样本推断2021年至今全覆盖。若只有重大新增路径，先提供兼容设计，不放开归档主机或格式白名单。

另离线核对年度包异常隔离：解码保存原值，Source按合约和请求日期检查OHLC，异常请求整体失败；不同合约的请求不得受牵连，也不得把失败结果记为空覆盖。两个历史异常的具体原行与失败原因须从冻结产物核实。

## 两条异常的准确隔离方式

`tools/archive/decode_annual.py`保留原字段及成员、行号，当前不在解码阶段以OHLC关系删除记录。`officialdaily.New`可加载这些可解析的数字记录；`Records`仍能取出原值。`Bars`在请求合约及交易日范围内检查，遇异常返回nil及带原件SHA/行号的错误，整次请求失败；不永久封禁合约，不删除整个年包。正常记录必须另按有据日历、生命周期发起请求并检查错误，不能把失败区间标为空覆盖。

fu2306/20230531另有空开高低、零成交量，也会被当前严格Bars拒绝；不把它当成正常对照，不用结算价补OHLC。本轮首次选择它作正向邻日、以及尝试从SHFE 2021年包选择lu均未通过，失败说明保留在独立目录。不能以两个已知异常清单代替逐条验证。

隔离承诺仅限可解析记录的价格语义。ZIP损坏、哈希、表头、重复键、未知合约或年度身份错误仍可使整个文档加载失败，当前没有声称实现容错解析全流程。XLS值是二进制单元格解码表示，不冒充原始十进制文本。

新增合成年度回归同时验证异常拒绝、正常日期/其他合约成功、原值保留；删除Source OHLC门禁后命中目标断言失败，工作区源码未被变异修改。真实复核器及输出留在取证目录，其合成日历范围必须随交接保留。

## 下一步兼容方案及停止边界

当前可继续归档SHFE/INE/CZCE已经验证的原件，不等待DCE/GFEX解阻。接收带来源、SHA和真实取得记录的合法本地原件可使用既有`identity-only`离线导入，但这只证明字节身份，不认证行情语义。

若取得新的正常官方公开路线，先冻结端点/请求参数/返回日期与业务错误判据，以近期、早期历史、无交易日期的有界样本验证，再分别提出：受控归档域名和方法白名单、明确新格式的离线解析器、正反向及恢复预算测试。保持Source/Bar/Store/Feed兼容，原件归档与严格回测资格分开；本轮不直接放开DCE/GFEX门禁或修改公共接口。若只能登录、验证码、客户端或降低TLS安全性，停在该边界并报告。
