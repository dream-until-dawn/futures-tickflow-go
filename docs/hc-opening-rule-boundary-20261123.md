# HC 夜盘首开参数边界复核

用同时写明交易日和夜盘日期的上期所收费公告作对照，比较生效前一日、生效日与下一月首日的原始结算业务表。按每个合约的交割月核对公告的例外及恢复条件。持仓边界另以历史版本及对应交易日轴复算，规则覆盖不完整的区间继续待核。

## 固定一手持仓边界

上期所历史手册和 2023 年风控修订附件均载有交割月前一月末调整至 30 手整数倍的要求。2024-10-23 版本对投机持仓明确同样边界，后续品种细则中使用一般持仓口径，并保留特殊情况可顺延一天的条款。适用范围须按版本与持仓类型核对。[历史手册](https://www.shfe.com.cn/upload/20180126/1516958675067.pdf) · [2023 年风控附件](https://www.shfe.com.cn/content/2023_BR/BR-FJ8.pdf) · [2024 年版 HC 细则](https://www.shfe.com.cn/regulation/exchangerules/historicalversion/202409/t20240903_802273.html) · [后续版本](https://www.shfe.com.cn/regulation/exchangerules/productrules/202512/t20251231_829963.html)

在已核交易日轴上，按普通固定一手且无顺延证据，hc2402、hc2409、hc2602 的月末收盘前退出边界分别为 2024-01-31、2024-08-30、2026-01-30。三次到期日修订均留在同一交割月，前后各推一次所得月末边界一致。此结果适用于该一手场景的退出边界，逐日开仓资格、历史版本无缺口证明及剩余首开参数映射仍待复核。当前未划定新的正式准入区间。
