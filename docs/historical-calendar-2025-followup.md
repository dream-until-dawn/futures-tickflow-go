## 复现与接入

证据原件根目录为`C:/Temp/tickflow-calendar-2025-20261112`；交接须附封存包，Git中的JSON不包含全部Word及官方年度ZIP。运行环境需要Go及Python，实际XLS/XLSX原件复算另需xlrd 2.0.2、openpyxl 3.1.5。

```text
python -X utf8 tools/calendar/annual/build.py --facts docs/evidence/annual-2025-facts.json --review docs/evidence/annual-2025-review.json --evidence-dir <evidence-root> --out <new-calendar.json>

```

使用者读取JSON的`series`交给`verified.New`，显式检查构造与查询错误；没有扩大embedded默认表。AD/OP上市前是ErrUncovered，不能补成休市。`DayOf/Covers`自然日期覆盖与`DayAt`绝对时刻覆盖不同：首段之前、末段结束及之后保守返回ErrUncovered，不可用本表回答12-31的21:00为已覆盖休市。相同品种跨年须合并连续Records为单个Series，不能追加重复ProductKey；尚未据此声称跨年整段同步已验收。

本批资格仅为官方公布连续交易安排。已公布时段、上市和假期的结论置信度高；全年逐笔连续性、全合约生命周期/挂牌全集、账户许可和资金政策、全年价格质量、点时可得性均不随之获证，不含集合竞价，也未穷尽未收录/未公开的盘中暂停。派生正文、解码文件的实际冻结登记时间与原件取得事件分开；年ZIP的2026-11-05本地复用收据不是首次HTTP取得，更不证明2025当时实时可得。
