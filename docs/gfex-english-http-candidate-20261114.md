## 预算与运行语义

每实例只允许1次实际请求，最多2MiB，单次总限不超过15秒，间隔至少1秒；`Limits`还须满足既有正数与超时大于间隔约束。新建无Cookie/凭据的client，不接收调用方client/头部，不忽略TLS、不自动重定向/重试；代理含账户凭据则拒绝。只允许目标精确字符串，HTTPS、HTTP其他路径、站点地图、数据链接也不自动开放。收到超限正文时保留至多一个探针字节并立即失败，实际字节照实计账，不把超限记成功。

复用`Download`的`native-http`、`Unauthenticated=true`、`SourceURL/SourceSHA`和恢复校验，保持旧Job序列化身份。`Complete`只表示传输读取完整；即便HTTP200也不是业务成功。实际采集须经`batch.Run`提供内容验证器，拒绝挑战、登录、脚本跳转或非业务正文；失败状态和原件保留，不重试。无通用挑战识别或页面脚本执行能力，不声称已取得GFEX正常正文。若有正常正文，引擎仅登记其明确链接，后续端点须另核具体范围。
