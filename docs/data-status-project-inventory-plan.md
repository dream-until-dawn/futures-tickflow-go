# 全项目数据台账扩展设计

2026-11-16，按使用者要求，把数据情况表从有限研究目录扩为全项目已有数据登记。只读盘点已有本地原件、源样本、消费者侧复用本库的官方目录、已验日历及现场证据，不新发市场请求，不改变任何准入。

## 数据结构

每个品种保留原研究统计，并增加按数据类型和来源分组的资料记录：实际字段观察起止、原行数量、有效/缺失数量（可核时）、完整性结论、最后取得时间、最后归档/索引时间、存放位置、证据摘要和读取层级。OHLC、成交量、持仓、结算、前结算、成交额独立统计，不能用整文件首末日替代每列有效范围。主表仍只写来源；详情列所有路线。

覆盖“已登记真实资料”而不是机器上所有临时文件：仓库真实源样本、官方累计目录和更新、EDB日线、其他供应商样本、已验历史日历、历史目录/生命周期和规则证据、分钟历史/现场记录。合成夹具、变异副本、迁移重复和构建产物不计行情。文件仅剩旧验收记录或目前无法读取时列为登记证据，不假装本轮读到原件。所有本次发现但尚不能分配到品种/数据列的真实资料保留在全局资料索引，不静默丢弃。

## 完整性和时间

“取得部分观察”“原始字段缺失/异常隔离”“已核制度日历范围”“原件当前待定位”分开，不生成无依据的完整率。没有官方挂牌全集和完整有效日历时，预期合约日分母为未知；首末跨度不能表示连续覆盖。不同来源及重复归档不相加。

最后更新时间必须携带种类：实际请求回执、仅本地归档事件、派生索引生成、文档登记。缺失时不取文件mtime或Git提交时间冒充数据更新；年度包的回执明说首个HTTP时间未解时不得显示为原始下载时刻。页面展示登记日期与行情末日，二者分列。

## 验证和维护

冻结新资料索引及各输入SHA；离线CI从公开汇总复现页面，不要求访问仓外行情。本机采集器只读重数实际记录并校来源身份，输出另建目录。测试覆盖各列不同末日、零/缺结算、源重复、未知更新时间、篡改输入和准入提升拒绝；浏览器验证详情、主表空白和筛选。旧研究统计和已封存原件保持不变，新汇总单独加入，记录尚未找到的输入。
