# 离线研究目录消费说明

## 作用与输入身份

`tools/research/catalog/build.py` 将冻结供应商目录、已取得日线CSV/完整收据和既有逐合约复核报告连接起来。它不联网，不采集新行情，不提供补值、价格选择、生命周期或交易准入接口。生成的 `historical-research-catalog-v1` JSON仅供研究定位和任务盘点，不是默认Source或完整市场证券主表。

输入固定为三份旧包的包外可信manifest SHA。工具每次读取文件都核清单中的安全相对路径、长度和SHA；锁表还约束CSV/收据身份、具体源代码及日线周期。CSV日期锚点、严格递增、行数和首末日独立回读，必须与冻结报告相同。报告中生命周期或金融资格被提升会拒绝。输入清单被改写不能靠一起重算文件SHA获得信任。

完整旧包核验与最小输入迁移有区别：`--verify-complete-packages` 会核全部成员、集合和字节。输出 `inputs/{shfe,cffex,czce}` 只保留本次读取的文件及原可信清单；迁移复算默认只验证所用输入，不谎称含437MiB原包的全部成员。对这个最小集合使用完整包选项会因缺无关成员而拒绝，属于预期。缺少实际需要的文件在读取该文件时拒绝。

## 消费字段

| 字段 | 解释及边界 |
| --- | --- |
| `symbol` / `source_key` | 研究规范键和原供应商键分开；例如 `CZCE.PF2105` 与 `CZCE.PF105`，收据请求必须对应后者，不自动猜年代 |
| `supplier_expiry_seconds` | 供应商原快照字段，仅用于本路线到期不早于2021的候选过滤；不是获证最后交易日 |
| `availability.state=nonempty` | 本路线已有完整非空响应，列行数、实际首末观察日和正文SHA；不保证交易日之间完整或上市前后无缺日 |
| `empty_unavailable` | 完整HTTP200、精确日线表头但无行；保留原failed收据，成功/覆盖均为false，不能当零价格样本 |
| `not_requested_on_directory_route` | 此有限目录路线没有请求；不表示全仓从未采样，也不表示合约不存在或数据源没有历史 |
| `reference_review` | 旧冻结对照结果的索引，包含参考日期缺失、未解决数值差异及日历未知行数，不是本轮重新独立重算全部价格字段 |
| `reference_transport_identity` | CFFEX明确是原生明文未认证参考；SHFE/INE/CZCE为已有官方HTTPS端点原件，不等同数据无误或PIT成立 |
| `interior_only` | 已有日历检查只在首末实际日线之间，不能认证挂牌起止、整个生命周期或未来日期 |
| `official_listing_day` / `official_last_trading_day` | 本目录一律null；需要额外官方材料，不能由实际第一/最后报价或供应商expiry填入 |
| `financial_eligible` | 本研究目录一律false；任何现有六品种制度资料也不自动授予这批数据完整回测资格 |

`summary.by_product` 按交易所+品种给候选、三种状态、实际行数、日历未知行数、待核差异及非空响应里的参考缺日数。后者不包括11个完整空响应，应与空响应单列，不能拿28个参考缺日冒称全范围只缺28天。144个数值差异是本目录路线SHFE/INE26加CZCE118，旧37个供应商间差异另册不重复合并。

## 重建与只读查询

以下路径均替换为实际包根目录；输出必须全新且在三个输入包之外，原件不会被修改：

```powershell
python -B -X utf8 tools/research/catalog/build.py `
  --shfe-package <shfe-input> --cffex-package <cffex-input> `
  --czce-package <czce-input> --out-root <new-output>
```

从迁移包执行其所带的同一脚本，三个参数分别指向包内最小 `inputs` 的三个子目录；不加完整旧包验证选项。报告是确定性JSON，可与封存输出逐字节比较。首次使用应核交接记录的包外可信manifest，再核该manifest中的catalog SHA；不能把刚从未知文件自行算的摘要当信任根。

消费者核完身份后，可按 `symbol` 建字典，读取状态和边界；本版本没有自动调用市场API、触发补采或提升准入的功能。`CY/PF` 首次上市目录关联另由 `listing.py` 给出：CY四位原码按原样关联；PF三位原码即使当前快照只有一个候选，也不输出“官方规范年份已证”。这些已知材料不新增本路线5,351个候选或价格样本。

## 当前结果与阻塞

本轮得到5,351个候选、89品种；1,954份非空响应/377,305行、11个完整空响应、3,386项本路线未请求。343,012个实际行仍缺既有获证日历范围；其余行也不自动获得全金融回测准入。具体摘要、可信身份、失败公报和复算收据见[本轮维护记录](offline-catalog-continuation-20261115.md)。供应商目录不是官方历史合约全集，仍缺更全面的官方挂牌/摘牌生命周期、其他产品制度资料、待核量价差异和现场特殊窗口等材料。该工具不会解除这些阻塞。
