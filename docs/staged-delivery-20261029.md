# 面向回测引擎的阶段性交付

2026-10-29，使用者明确同意先做阶段性交付。能力核验基线为 `c74e1432a4402e6518ee6b977a96de3a7f66afcd`；本次只补交付说明，不修改生产接口，不创建标签。原v0.11完整范围中的停夜盘Live/L9转为后续专项，仍保留未验状态；这不是原完整发布范围全部通过的声明。

## 使用者现在可以获得什么

| 能力 | 可用入口及用途 | 接入边界 |
| --- | --- | --- |
| 历史行情取数 | `source/shinnysource`拉具体合约1m；`source/sinasource`和`source/cffexsource`提供各自支持的具体合约日线 | 天勤需账户；本库天勤日历覆盖从2020-05-06开始，不把上游更早数据深度当作本库可用范围。结算价和品种覆盖须按源、合约、区间核验 |
| 增量准备与持久化 | `Syncer`按交易日同步、报告缺口与异常；`store/segfile`保存行情和coverage，供重复回放 | 调用方检查同步报告和coverage；不能仅凭调用无错误认定数据完整 |
| 交易时间模型 | `calendar/embedded`与`Period`处理交易日、夜盘归属、休市段和周期边界 | 调用方提供准确交易日表；当前模板不代表所有历史制度，未收录品种和过早日期不给默认答案 |
| 逐根历史回放 | `NewFeed`、`Next`、`View`提供按时间推进、历史窗口、OHLC及量仓字段 | 区间须在一段coverage内；用完关闭Feed，并检查Err；数据读取中失效时，已交出的根也须作废 |
| 多周期与指标 | `Feed.TF`提供最后已收盘辅周期；显式`AggRule`聚合；内置MA、EMA、MACD、KDJ、RSI、CCI、BOLL及预热状态 | 必须显式选聚合口径；检查Ready、Defined与不完整根标记，不把NaN当零；每日辅周期的结算价取决于数据入口 |
| 主力连续研究 | `continuous`提供日线选约、换月和复权；主连Feed可读实际合约、原始收盘价、换月日和价差 | 主连Feed只支持日线；不自动落库，不提供日内主连Feed；规则无法选约的交易日不会猜测 |
| 记账内核衔接 | 独立`adapter`模块将未复权具体合约Bar转换为固定版本futsim.Bar，供Advance守卫和计价 | 转换High/Low/Close、合约、交易日和时间；不传Open、结算、量仓及Flags；不拆跨休市根，不撮合，不自动结算，调用方负责过滤不完整根 |

推荐接入顺序：提供交易日和具体合约，统一注入日历；取数同步并核对报告；从已覆盖的Store构造Feed；逐根读取主周期、已收盘辅周期和指标；由回测引擎自行执行策略、撮合与账户流程。需要使用adapter时，应读取实际合约的完整未复权OHLC，不能把复权High/Low与RawClose拼接使用。

## 证据与验收范围

历史同步、聚合、Feed、指标和主连以[能力契约](contract.md)中的已实现表及各模块测试为准，不能把该文档的v1目标表整体当成已实现。具体合约普通夜盘、日盘现场及独立历史对账见[10/28记录](day-progress-20261028.md)和[10/29记录](day-progress-20261029.md)。这些是限定合约和窗口的实证，不是全市场或普遍四秒保证。

阶段新增能力的API树比、外部无replace消费与兼容性反例见[发布草案](release/v0.11.0.md)。`embedded.New`的普通调用仍可用，旧单参数函数值赋值须包装；外部消费者须显式固定根模块和adapter版本，不能依赖仓内replace。固定提交伪版本已有消费验证，尚无本阶段发布标签。[adapter说明](../adapter/README.md)列明固定记账内核版本及字段边界。

基线已通过三个Go模块检查、75项Python测试及跨平台CI。本次纯文档变更另经测试名称守卫、发布正文提取守卫、doccheck和差异空白检查通过；基线结果不冒充后续提交的全量检查结果。
