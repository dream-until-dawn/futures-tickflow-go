# 长缺口控制的离线标定

2026-10-23：使用者取消外部评审，并授权直接操作 Git；继续保留自动检查与证据记录。先增加测试侧控制与标定，再接真实行情运行器。

控制方案：初始两根已交出且队列排空后，同步调用包内 drop 关闭被测 socket；停止 Next、推进假交易时钟，再在同一 Live 实例恢复 Next。暂停时不存在活 socket，不会把消费停顿误认为行情断线；不延长握手、不修改生产重连和冻结参数。

使用默认冻结参数，恢复窗口固定为 30 根。分别制造 29 与 31 根已完结根缺口；二者均因窗口低端晚于断点而需要历史补齐，不能把“缺口小于 30”误认为必然无需补齐。逐根验证时间、交易日及 O/H/L/C/V/OI，连接计数证明触发历史通道。负向标定删除历史中的一根，必须拒绝，不能静默跳过。

该标定只证明本地协议假服务下的控制与补齐行为，不证明真实网络持续断线的恢复效果，也不等于真实行情运行器已完成。
