# 收盘末根反例筛查

已有 analyzeTail 按固定日盘段汇总，不能只因退出码为零便断言某一个指定末根被完整观测。新增独立离线入口 shinny-session-end，明确传入合约和收盘时刻，复用原始 JSONL 格式而不 import 被测库。

先标定：缺末根、仅收盘后才首次见末根、重复帧、超过四秒的真实修改、帧时序反转、未覆盖收盘时刻。只对给定根的 O/H/L/C/V/OI/open_oi 实际变化更新时间；相同值重发不计。原始帧必须显示收盘前的正常分钟推进；缺资料返回无结论/失败。

本机接收时刻 L-C 超过四秒是需要进一步核实的反例候选，可能含网络投递和本机偏差。未超过只说明这份记录尚未反驳四秒，不证明未来或所有品种均足够。文件末帧的时刻不能当作 socket 实际关闭时刻；观测截止与完整录制状态必须从录制日志核对，历史对账另做，不把单纯离线筛查叫作完整验收。

白天可收集 15:00 末根样本供工具验证，仍不能代替夜盘 23:00 样本。本次授权截止 17:00，不启动夜盘取数。
