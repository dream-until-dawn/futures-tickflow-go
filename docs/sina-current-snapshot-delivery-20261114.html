使用者现在可用什么

可以按固定提交和数据SHA离线读取所有已取原件，使用source/sinavendor.Parse获得d/o/h/l/c/v/p/s字符串值、文档身份和原行号。全部身份固定vendor/sina/request-bound；响应没有交易所字段，规范Symbol中的市场仍是调用方/供应商目录声明，不能当官方原码与挂牌认证。

records, err := sinavendor.Parse(document) // 无需日历，严格验Ref/SHA/URL/包装/日期/重复键
src, err := sinavendor.New(independentlyVerifiedCalendar, documents, now)
bars, err := src.Bars(ctx, request)        // 仅日线；缺日/坏值/未知日历/未收盘整次拒绝

有独立可信日历时，可显式接入Source→Syncer→segfile→Feed。必须独立分合约建库，并连同Records附件与原件清单一起迁移；段文件本身只有Bar/Flags，不完整保留原件关联。没有可信历史日历时，应停在原件/字段研究层；本轮DCE/GFEX未获证的历史时段不能由报价日期反推成官方日历。

Bar使用float64，不承诺财务精确十进制。原始十进制字段仍在附件及原件中；量仓严格整数并限制浮点安全范围。成交额未知为NaN；零/缺结算不补收盘。Caps字段能力不代表逐日完整或金融资格。合约日重复/版本修订须显式选版本，不能静默覆盖。

显式精确null工具默认关闭；公共Downloader、batch.Run、Source的严格默认完全保持。工具成功退出只表示原件任务完成，不能代替逐件failed-quarantined/received状态。7份null继续交公共Parse仍应报错且无行，不进入Source/Syncer覆盖。此工具不提供tick、分钟、盘口、交易权限或资金操作。
