为何选这个新入口

四个有界浏览检索词发现快期/信易官方EDB历史服务文档，它明确写免费无需token可取最近一年分钟和任意历史区间日线，并列内部研究/下载/复盘场景、Asia/Shanghai字符串时区、Unix纳秒起始时间和volume手数。本次必须先完整归档正常HTTPS原文，核正文后才冻结数据请求，不能只靠搜索摘要发取样。

EDB是不同于已有WebSocket的CSV传输入口，仍属Shinny供应商，并非独立于Shinny的第二行情上游；官方交易所原件才是拟对账的独立来源。免费研究访问不等于可再分发全量或商业供应授权，原始供应商CSV先只在仓外保存，不推Git。文档的预估历史起点、示例合约不证明真实挂牌全集，不照抄可能不具身份依据的例子。

分期和预算

  1. 先单独取上述文档一次：新目录、2MiB实际字节上限（含探针）、15秒总限、正常TLS、匿名GET、不跟转/重试/JS/Cookie/认证。若失败/未知停止该主机，不发业务请求。
  2. 原文取得并核对免费范围、时间与单位后，在已持有的2025官方年度ZIP中核实具体合约和日期；优先挑2025-11-18，避免落在最近一年分钟边界以前。选择真正有官方原行的具体月码，不用主连/指数。
  3. 另冻结最多4条精确CSV GET：两具体合约各一个交易日日线和一个完整分钟时段。总8MiB，每件2MiB/15秒、至少2秒间隔；只在完整文档与具体身份就绪后取样，不登录、不取token、不购买、不绕免费范围。一项失败/空/格式不符即停止该数据主机，其余未尝试如实保留。参数仅用正式GET接口文档支持的period/symbol/start_time/end_time，不猜私有API。
  4. 如果取得真实CSV，保留UTC/字节/SHA、逐字面量价格和纳秒整数；用既有获证日历核分钟/跨夜归属、聚合OHLCV及收盘OI，对照同键官方原字段。服务未提供的成交额/结算不补造，不以float近似掩盖原文本差异；没有对应官方数据则不说对账成功。
