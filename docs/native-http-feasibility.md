# DCE/GFEX原生HTTP：隔离候选与有界验证

本批另起于主线154845d，不改已完成的PX/SH证据提交。已直接读取引擎会话01a19f51-fb63-7a73-bf9e-b69e3d44a2b6中的人类答复：批准按其`docs/native-http-upstream-proposal.html`做“有界验证及必要兼容扩展”。授权只到候选和原件可行性，不包含本候选合并、tag、部署、资金或严格行情准入。

## 先行设计

旧NewDownloader、旧Job字段和序列化身份不变；新增独立显式构造入口，只有该入口可按逐URL/GET清单获取原生HTTP。当前只实现已证实公开的首页及协会明列的业务参数页面，不实现没有网站依据的POST、任意查询或脚本抓取。方法白名单即GET，不能用未来可能需要POST来提前放宽。

每项授权绑定协会HTTPS原件Ref、SHA和本次独立核验的原始正文，必须实际包含相同目标业务页的静态href或jQuery常量href赋值（不执行脚本）。首页仅由该明示链接的同一官方主机推出并明确记录。只接受www.dce.com.cn和www.gfex.com.cn的有限业务路径，不接受旧有未证实www.dce.cn。禁止URL账户信息、查询/片段/端口/转义路径，拒绝未知源、重复项和空清单；来源SHA只锁字节，不自证协会或明文目标真实性。

构造器自建无CookieJar的公开读取client；自建标准Transport，不继承可变全局默认client或TLS配置，拒绝带认证代理URL，不跟随重定向、不重试、不做HTTPS失败降级；关闭连接复用以避免复用连接自动重发。保持现有请求/总字节/间隔/超时守卫，新增每件2MiB限制。获批真实上限12请求、16MiB总量、2MiB/件、15秒/次、间隔至少1秒；连接失败同样消耗预算，超限最多读取一个探针字节并保留前缀。

原生HTTP元数据必须标注native-http、未认证明文及关联出处URL/SHA；成功恢复必须复核该标签和当前显式授权，不能删除标签伪装HTTPS。默认构造器对远程HTTP继续在联网前拒绝。仍由内容验证器判断是否有业务资料；HTTP200、明文正文和SHA都不授予市场/金融资格。旧JobSHA不变，但新远程HTTP成功收据不得用默认或无下载器恢复后重新包装。

## 执行与门禁

先离线验证默认拒绝、显式读取、错误方法/URL/来源/凭据/端口/路径、重定向、预算/时限/失败正文、恢复标签和旧JobSHA，再故意去除默认拒绝、逐URL清单、明文标签守卫，确认具名测试按目标失败。反例只在仓库外副本，原件不修改。完整本仓模块测试及race后，冻结真实清单和来源原件，实际请求前核其SHA。只读GET，不猜端点；一旦无业务原件即在实际失败处停，不为用满预算继续盲试。

当前人类批准及协会原件仅作为新入口线索：已获正常HTTPS原件还须本会话逐字节复核。INE旧缺证路线及DCE/GFEX已失败HTTPS路线不重试。真实结果、预算、每项URL/原件SHA、具名正反控制及限制将追加本记录和机器索引；向已获人类授权的引擎会话回报准确候选，由其独立复核。
