# 长缺口独立文件复核

运行器通过后，再使用 Python 标准库读取封存文件，不 import Go 库、不调用运行器分析函数。记录分析前后 SHA256，严格逐行解析 JSON，拒绝损坏尾部。此脚本针对本次同一日盘连续时段的执行单，不对跨日或跨休市计划给出结论。

核对执行单、控制事件、原始参照、最终历史和 Live 输出五组资料：标签与交易日完整、O/H/L/C/V/OI 一致、编号连续、参照只有一条连接、真实断开/恢复之间至少覆盖 31 根完整交易分钟，且这些根在参照中确实于盘中出现。不能仅以 32 分钟墙钟或运行器 PASS 代替证据。

控制日志是客户端动作证据，原始帧是参照行情证据；两者联合支持受控暂停恢复结论，不支持默认三次重试自动熬过长断网。分析器先以完整样本和缺帧、改价、错交易日、短实际暂停、损坏原始流等反例校验，再用于今天实测。

复核命令：python tools/audit/review_long_gap.py <封存根目录>。只向 stdout 输出报告，不修改封存文件；报告列出采集代码 SHA、四个 JSONL 分析前后的 SHA256，以及执行单和运行日志的 SHA256。要求运行器日志已成功结束、执行单与采集参数一致且分析期间未改变。测试覆盖完整封存目录、未结束日志、执行单不一致；缺帧、改价、错交易日、重复、控制偏移、完整根不足、重连、时钟倒退、缺少前置输出、快照冒充观测、非有限或布尔价格、编号标签改写及损坏/非标准 JSON 均拒绝。Python 自检链已自动包含这些测试。
