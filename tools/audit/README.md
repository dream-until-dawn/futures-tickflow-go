# `tools/audit/` — 复现某一条**已记录的测量**的一次性脚本

和 `tools/probe/` 的区别，一句话：

| | `tools/probe/` | `tools/audit/`（本目录） |
|---|---|---|
| 跑的频率 | **每次送审都跑** | 只在复核某条记录时跑 |
| 断言什么 | 「外部世界还是那样」 | 「当初那个数是怎么量出来的」 |
| 耗时 | 秒级 | **可能几分钟**（本目录第一个脚本约 6 分钟） |
| 不跑的后果 | 数据源变了没人知道 | 记录里某个数变成**不可复原** |

**这个目录存在的理由**（2026-09-08 学到的，代价是同一段文档改了三次）：

> 有些格子不是审计漏了，是**它已经无法被审计了**——
> 而记下当时【怎么量的】，本来可以让它可审。

所以：**凡是写进 `docs/probe.md` 的数字，如果它不是一条探针的输出，
产生它的脚本就该落在这里。** 不然下一个人只能「回想」，而回想不是测量。

## 现有脚本

- **`rebuild_docs_test.py`** —— 重建 `docs_test.go` 里那三张生成的表，**一步到位**。
  带 `--drill`：**演练一次还原路径**（故意写坏 → 还原 → 比对逐字节相同）。
  因为「失败就还原」这条分支平时不会被走到，而**没被执行过的路径与不存在的区别，
  只在读者的印象里**。
  改过五份载体里任何一份，跑它。**它是一个脚本而不是几条命令**，因为原来那条
  用 `;` 串起来的流水线在截断步失败之后照跑，把 `docs_test.go` 写坏过一次。
  每步断言 / 动手前整份备份 / 写完跑 `gofmt` + `vet` / **失败就逐字节还原**。

- **`section_move_check.py`** —— 验「把一条已登记规矩挪到另一个小节底下」会不会被抓到。
  它**应当红**（登记项带所属小节）。自带对照组：真删那一行也必须红。

- **`render_escape_check.py`** —— 量「规矩以**字节不变的方式**失效」那一类还剩多大：
  A2（围栏包成代码块）、A3（行首四空格）各试一次，外加一个对照组（真删那一行必须红）。
  **它跑出来的绿是【已知边界】，不是缺陷**——那一类写在 `docs/method-landing.md` 第三类。
  改了守卫之后跑一遍，确认边界没有悄悄变宽。

- **`sweep_carrier_rules.py`** —— 用一个**和生成器不同的网**扫荡登记表的覆盖面：
  把五份载体里每一行含 `**` 的各删一次（299 行），看守卫响不响。
  **用生成器自己的模式测生成器，得到的一定是满分**——这个脚本存在就是为了绕开那一点。
  它自带对照组（删一份**非载体**文件的三行，必须全绿），因为
  「全都响了」和「这个 harness 永远返回非零」在输出上长得一模一样。

- **`gen_rule_anchors.py` / `gen_quoted_rules.py`** —— 生成 `docs_test.go` 里那三张表（小节锚点 / 逐条登记 / 普查数）。
  **登记表不手敲**：手敲的登记表会在你以为它覆盖住的地方漏掉东西
  （第一版只认 `> **…**` 一种格式，漏了 11 条独立加粗行）。
  改完规矩跑一遍，把输出贴回 `docs_test.go`。

- **`gfex_caliber_check.py`** —— 同一段字节，两种计数口径各数一遍。
  写它是为了验证「差 4 是口径不同」这个解释——**结果两种口径给出同一个数，
  解释不成立**。留着它，是因为下一次再拿「口径不同」当解释时，跑一遍就知道了。

- **`gfex_offset_recheck.py`** —— 复现 `probe.md` §5 那张「按位置采样」的表。
  按**绝对字节偏移**重取（不是按百分比：百分比的分母是文件总长，它会变），
  用来分辨「文件内容变了」还是「窗口挪了」。
  对照组焊在函数里：每个窗口必须①正好 262144 字节②`exchange_id` 计数 > 0，
  否则报「取数失败」而**不报计数**——因为一次失败的取数和「这里真没有 GFEX」
  在输出上长得一模一样。
